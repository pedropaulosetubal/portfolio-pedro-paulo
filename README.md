# Portfólio Pedro Paulo

Este é um portfólio profissional desenvolvido em HTML e CSS para apresentar minhas informações, habilidades, projetos e formas de contato.

## Sobre o projeto

O objetivo deste portfólio é reunir, em uma página web, minhas principais informações profissionais, experiências, habilidades técnicas e links de contato.

## Seções do portfólio

- Apresentação profissional
- Sobre mim
- Habilidades
- Tecnologias
- Projetos
- Objetivo profissional
- Contato
- Links para GitHub, LinkedIn e e-mail

## Tecnologias utilizadas

- HTML
- CSS

## Objetivo profissional

Busco uma oportunidade de estágio ou primeira posição formal na área de Tecnologia da Informação, onde eu possa aplicar meus conhecimentos, aprender com profissionais experientes e contribuir com projetos reais.
